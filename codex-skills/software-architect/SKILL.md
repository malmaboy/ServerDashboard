# Software Architect

Use this skill when the primary task is structural design rather than immediate code changes.

## Workflow

1. Clarify business goals, constraints, and quality attributes.
2. Identify the core domains, boundaries, and integration points.
3. Compare 2-3 viable approaches.
4. Choose a direction with tradeoffs.
5. Produce a practical implementation path.

## Focus Areas

- Service and module boundaries
- Data flow and contracts
- Reliability and scalability tradeoffs
- Migration strategy
- Technical debt containment
- Evolutionary architecture

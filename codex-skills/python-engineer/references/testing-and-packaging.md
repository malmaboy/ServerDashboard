# Testing And Packaging

## Test prompts

- Is there a targeted pytest or unittest path for this change?
- Is the bug reproducible in a small fixture?
- Are edge cases and regressions covered?

## Packaging prompts

- Is the project using `pyproject.toml`, Poetry, setuptools, or requirements files?
- Are version and extras changes intentional?
- Does the change affect CLI entry points or import paths?

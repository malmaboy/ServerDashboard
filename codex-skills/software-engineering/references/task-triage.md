# Task Triage

## If the request is vague

- Identify domain: backend, frontend, infra, data, or CI.
- Identify task type: bug, feature, refactor, review, or explanation.
- Identify impact: local file, single service, shared contract, or production risk.

## Escalate mentally when

- Multiple services or repos are involved.
- Schema or public API contracts change.
- Deployment, auth, payments, or data deletion are in scope.
- The task asks for a review of risky code without tests.

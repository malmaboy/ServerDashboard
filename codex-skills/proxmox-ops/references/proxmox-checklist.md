# Proxmox Checklist

## Incident checklist

1. Check node reachability and host load.
2. Check cluster health and quorum.
3. Check storage availability and free space.
4. Check VM/LXC state and recent task logs.
5. Check bridge, VLAN, firewall, and guest IP assumptions.

## Maintenance checklist

1. Confirm backups exist and are recent.
2. Confirm replication and HA implications.
3. Confirm target storage and network capacity.
4. Define rollback and guest verification.
